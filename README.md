# Thanmaya Sri Navya Portfolio

Animated, responsive portfolio for Thanmaya Sri Navya, an Electrical and Electronics Engineering student at PSCMR College of Engineering and Technology.

## Local development

```bash
npm install
npm run dev
```

The profile photo is stored at `public/profile-photo.jpeg` and is used in the hero portrait. Replace it with Thanmaya's photo before publishing.

## GitHub Pages

Create a GitHub repository for this project, add its remote, then run:

```bash
npm run deploy
```

The `deploy` script publishes the `dist` folder to the `gh-pages` branch. Enable GitHub Pages for that branch in the repository settings.# React + Vite

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
